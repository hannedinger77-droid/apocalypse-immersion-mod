# Contributing to Apocalypse Immersion

Thank you for helping improve **Apocalypse Immersion**!

## How to Contribute
1. **Fork** the repository and create a new branch for your feature or bug fix (`git checkout -b feature/my-improvement`).
2. Keep changes modular inside `com.apocalypseimmersion` (server logic) or `com.apocalypseimmersion.client` (client rendering/audio).
3. Test your build locally with `./gradlew build --no-configuration-cache` on **Java 17**.
4. Open a **Pull Request** describing what your change does and which mods (e.g., TaCZ, Oculus, Embeddium, Simple Enemies) you tested it with.
